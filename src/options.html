Settings

Each time you click the toolbar button, the address of the current page is sent to the places switched on here, and nowhere else.

Mastodon servers

One server and its access token per row. Mastodon only lets logged-in clients search posts, so without a token a server can only be checked for trending links.

Lemmy servers

One server per line, no token needed. Lemmy can search posts by their link. Each server only knows the communities it follows, so a few large ones work best.

Other places

Showing results

Only the results tab uses these colours. The popup follows Firefox's own.

No containers found. Check that Multi-Account Containers, or Firefox's own container tabs feature, is switched on.

Export and import

Exports the settings as last saved. Tokens give access to your Mastodon accounts, so if you include them, keep the file in secure storage (a password manager or an encrypted volume) and delete copies you no longer need.

Importing fills in the form above so you can review it. Nothing changes until you press Save.

Getting a Mastodon token

On your server open Preferences → Development → New application, tick only read:search and read:statuses, save, then copy "Your access token".

Tokens are stored locally in this browser (not synced), and are only ever sent to the Mastodon server on the same row.
